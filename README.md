# CrossGOverlay
Crosshair overlay for Windows.

## Run

```bash
dotnet restore /home/runner/work/CrossGOverlay/CrossGOverlay/CrossGOverlay.slnx
dotnet run --project /home/runner/work/CrossGOverlay/CrossGOverlay/src/CrossGOverlay/CrossGOverlay.csproj
```

The app opens a transparent, always-on-top crosshair at the center of the screen.
